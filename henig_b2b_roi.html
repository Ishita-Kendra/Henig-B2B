B2B ROI Estimator

The same 3 packages as the Trade Strategy Tracker — but every number here is a live input. Change any assumption and every package recalculates immediately.

How every package is calculated: channels with a published audience (a directory's member count, a show's visitor count) run Reach → Leads → New Accounts → Revenue → ROI. Ads (Google/Meta/LinkedIn) run on Budget ÷ Cost-per-lead instead, since they scale with spend, not a fixed audience. Cold email/LinkedIn outreach runs on a single Contacts × direct conversion % — deliberately one stage, not a multi-part funnel, since chaining separate response/meeting/close assumptions proved too speculative to trust. Platforms you get found on (RapNet/IDEX/VDB) and relationship-based schemes aren't run through this model at all — see "not modelled" below.
