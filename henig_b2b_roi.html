B2B ROI Estimator

How much does each trade channel actually return? This is a transparent, adjustable model — not a fixed answer. Every number below comes from four assumptions you control; change them to Henig's real conversion data as it becomes available.

How this is calculated: for every channel with a published audience size (a directory's member count, a magazine's circulation, a show's visitor count), the model runs Reach → Leads → New Accounts → Revenue → ROI using the four assumptions below. Channels without a published, push-style audience (platforms you get found on, relationship-based referrals, visit-only venues) are not run through this model — they're listed separately with the reason why, rather than assigned a made-up number.
